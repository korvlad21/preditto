## Adding a Module

When a task identifies a real module, create <module>/overview.md and add a short entry here with its responsibility, source area, and a relative link to that overview. Derive module names from current architecture and reuse established names. Add new modules as the project evolves; do not pre-create example domains.

Keep this index concise. Store architectural findings in the module's notes and use links for related modules. Follow [module research](../../.aiassistant/rules/module_research.md) and [knowledge accumulation](../../.aiassistant/rules/knowledge_accumulation.md) for content and maintenance.
